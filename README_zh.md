# device_board_iscas

## 简介

#### ISCAS简介

中国科学院软件研究所（ISCAS）智能软件研究中心（ISRC）的使命是以智能驱动软件发展，以软件支撑智能创新。面向智能计算发展趋势，瞄准高性能、高安全、低功耗、低延时等需求，研究智能基础理论与模型、软件新结构与编译构造方法、内核和运行时环境等，打造适配通用处理器、智能芯片和开放指令集的操作系统和编译工具链，建设开源软件可靠供应链和安全漏洞平台，研发智能无人系统仿真测试环境，支撑智能计算生态和重要行业应用。

#### 开发板简介

- [树莓派系列]

树莓派是一款基于ARM的微型电脑主板，以SD/MicroSD卡为内存硬盘，卡片主板周围有1/2/4个USB接口和一个10/100 以太网接口（A型没有网口），可连接键盘、鼠标和网线，同时拥有视频模拟信号的电视输出接口和HDMI高清视频输出接口。


- [树莓派4B]

树莓派4B（Raspberry Pi 4 Model B）。 目前该版本已通过了3.2.4Release版本的兼容性认证，适配了Wifi功能，支持HDMI显示，可以使用GPU渲染。
